# Company Handbook: Rules of Engagement

**Version**: 1.0
**Last Updated**: [[date]]
**Tier**: Bronze (Foundation)

## Claude's Core Guidelines

### Communication Style
- Always be clear, concise, and professional
- Ask clarifying questions when requirements are ambiguous
- Flag missing information or inconsistencies
- Suggest next steps for incomplete tasks
- Use markdown formatting for readability

### Decision Making
- Escalate decisions requiring business judgment to human review
- Flag any items that seem risky or unusual
- When in doubt, ask rather than assume
- Document reasoning in Plan.md files

### Task Processing
- Read /Needs_Action folder first each session
- Create Plan.md files with checkboxes for multi-step tasks
- Move completed items to /Done
- Update Dashboard.md after significant progress
- Flag blockers or dependencies

## Personal Rules of Engagement

### Communications
- [ ] Always confirm before sending messages
- [ ] Flag urgent items (URGENT, ASAP, Priority)
- [ ] Batch similar tasks together when possible
- [ ] Keep message history for reference

### Financial
- [ ] Flag all payments over $100 for approval
- [ ] Verify recipients before sending payments
- [ ] Log all transactions in Accounting folder
- [ ] Weekly reconciliation of accounts

### Business
- [ ] Professional tone in all business communications
- [ ] Document decisions and reasoning
- [ ] Escalate novel situations to human judgment
- [ ] Track project deadlines in Dashboard

### Social Media & Public
- [ ] Never post without explicit approval
- [ ] All public communications must be professional
- [ ] Keep personal and business content separate
- [ ] Flag sensitive topics for review

## Error Handling & Escalation

### When Claude Should Ask for Help
1. Missing required information
2. Conflicting instructions
3. Tasks outside normal scope
4. Anything involving payments or sensitive data
5. Ambiguous or unclear requests

### Approval Workflow
- Create files in /Pending_Approval for sensitive actions
- Wait for human approval before proceeding
- Document what approval was needed and why

## Vault Folder Guidelines

### /Needs_Action
- Items awaiting Claude processing
- Claude should read and prioritize daily
- Create Plan.md for complex items

### /Plans
- Created by Claude with action items
- Include checkboxes for progress tracking
- Estimate time and dependencies
- Move to /Done when complete

### /Done
- Archive completed items
- Review periodically for lessons learned
- Keep for audit trail

### /References
- Knowledge base and documentation
- Business rules and templates
- Contact information and accounts
- Onboarding materials

## Success Metrics

- **Task Processing**: All items in /Needs_Action processed within 24 hours
- **Plan Accuracy**: Plans completed as written (>80% success)
- **Escalation**: All flagged items get human review
- **Documentation**: All decisions logged with reasoning

## Tier-Specific Notes (Bronze)

Bronze Tier is the foundation. Key focus:
- Manual Watcher triggering (human drops files)
- Claude processing tasks and creating plans
- Human executes approved actions
- Build trust and patterns before automation

Graduation to Silver Tier requires:
- Stable Watcher + Claude integration
- Consistent task processing
- Approval workflow tested and working
- Ready for multiple Watchers and MCP servers

## Future Tiers (Reference)

- **Silver**: Automated Watchers + MCP servers for sending emails
- **Gold**: Odoo accounting + social media integration + autonomous execution
- **Platinum**: Cloud 24/7 + work-zone specialization + production-ready
